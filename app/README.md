# Player Value Forecaster

CMU 24-679 Project 1 (Yunus Polatoglu & Jack Stevens). Filter players by league, country, nationality, age and position, then select one to see their Transfermarkt value history and a 1 to 3 season forecast with a 10 to 90% range.

Data: Transfermarkt via Kaggle (`davidcariboo/player-scores`, `xfkzujqjvx97n/football-datasets`). Coursework only.
